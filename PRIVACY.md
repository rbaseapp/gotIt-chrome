# GotIt Chrome Extension Privacy Policy

Last updated: 2026-09-16

GotIt helps users save words and phrases they choose while browsing. The extension does not collect the full page, browsing history or page HTML.

When a user explicitly asks to save or preview a selection, GotIt may process the selected text, the sentence containing it, the page title, the page URL, a page-language hint and the capture time. This data is sent to the GotIt service to generate a translation preview and, only after confirmation, to store the learning item and its context.

Account information and authentication are handled by rbase Core. The extension stores the minimum session material needed to remain signed in. Access tokens are kept in extension session storage; the rotating refresh token is kept in extension-controlled local storage. Both stores are restricted from content scripts. The extension never places translation-provider API keys in the browser.

GotIt does not sell captured content or use it for general advertising. Product telemetry, if enabled in the future, must not include selected text, sentence text, full URLs or translations without a separate explicit policy and user disclosure.

Users can stop collection by not invoking a capture, disable the optional floating action and revoke its site permission, sign out to remove local session data, or use GotIt account/library controls to delete stored items.

Contact details and the public policy URL must be added by the publisher before submission to the Chrome Web Store.
